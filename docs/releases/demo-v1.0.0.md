## 冻结内容

该版本是已经完成视觉与交互评审的确定性前端演示，包含高层工作台、简报、会话、项目、文件、记忆、个人设置、管理端和十个标准演示场景。

## 使用边界

该版本中的账号、经营数据、回答、任务、文件解析、外部调用和推送均为演示样本，不得作为客户生产系统交付，也不得与客户真实数据混用。

## 维护规则

- Demo 紧急修复从该标签建立独立修复分支，并重新发布新的 Demo 补丁标签。
- 生产化代码只进入 `codex/production-foundation` 及其后续生产分支。
- 生产前端可复用 Demo 的视觉组件，但必须通过显式运行模式隔离演示适配器与真实 API 适配器。
- 在线 Demo 的发布动作必须单独确认，生产化构建和本机部署不得自动覆盖它。
