# 高层 AI 秘书原型

依据《高层AI秘书原始Demo功能设计说明书》实现的可交互产品原型。产品包含面向董事长的高层端，以及面向企业管理员与 FDE 的管理端，适合功能评审、连续演示和后续接口联调。

## 本地运行

要求 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。构建与验收命令：

```bash
npm run lint
npm test
```

## 演示账号

| 角色 | 账号 | 密码 | 说明 |
| --- | --- | --- | --- |
| 董事长 | `chairman` | `Demo@2026` | 首次登录必须修改密码，例如 `NewPass2026` |
| 企业管理员 | `admin` | `Admin@2026` | 可进入配置与运行管理界面 |

连续讲解时，可在高层端右上角打开“演示”入口，按说明书第 22 章顺序运行 10 个标准场景。

## 已实现范围

- 登录、首次改密、角色隔离、错误反馈与模拟锁定
- 高层首页、每日变化、每周简报、历史会话、长期记忆与个人设置
- 经营数据、当前会话文件、通用助理和公开研究四类处理路径
- 歧义澄清、会话范围、处理进度、中止、失败恢复与继续追问
- 总体盘面、目标进度、变化、预测、客户、交付、回款、组织与人员等结构化回答
- 图表与表格切换、来源说明、复制结论、保存图表、飞书内容预览
- 文件上传、解析状态、当前会话可见、删除确认与文档问答
- 管理端账号、模型、数据源、字段映射、同步、模拟数据、自动任务、飞书、能力范围与运行状态
- 桌面端与移动端响应式界面，以及键盘和基础无障碍状态

## 原型边界

当前版本是确定性前端原型：数据、Hermes/MCP 调用过程、飞书推送、Anspire 分析、文件解析和后台任务均以固定演示样本与交互状态模拟。它不会连接真实企业数据库，也不会向外部系统发送消息或文件。后续接入时应保留现有状态模型与隐私边界，将模拟动作替换为受鉴权、只读和可审计的服务接口。

## 主要文件

- `app/page.tsx`：产品状态、界面与交互
- `app/prototype-data.ts`：固定演示数据、回答模型与场景
- `app/globals.css`：视觉系统与响应式规则
- `tests/rendered-html.test.mjs`：构建产物与功能契约检查
