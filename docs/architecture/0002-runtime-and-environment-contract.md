# ADR 0002：运行环境与配置契约

- 状态：第一阶段实现契约
- 日期：2026-07-27

## 环境分类

| `APP_ENV` | `APP_MODE` | 用途 | 是否允许演示种子 |
| --- | --- | --- | --- |
| `local-demo` | `demo` | 演示者本机的脱敏演示 | 是，且必须显示 Demo 标识 |
| `customer-template` | `production` | 客户空白安装模板 | 否 |
| `test` | `production` | 自动化测试 | 仅测试工厂数据 |

`APP_ENV` 决定数据、文件、备份和日志隔离；`APP_MODE` 决定产品是否允许使用演示能力。两者不能互相替代。

## 服务端配置

服务端至少使用以下运行时配置，实际变量名可由实现层映射，但语义必须保持一致：

| 语义 | 约束 |
| --- | --- |
| 数据库连接 | 只在服务端可见；每个环境独立数据库和账号 |
| Session 密钥 | 至少 32 字节随机值；不得复用数据库密码 |
| CSRF 密钥 | 至少 32 字节随机值；与 Session 密钥分离 |
| 文件加密密钥 | 32 字节随机值；支持密钥版本标记，不写入文件元数据明文 |
| 文件存储根目录 | 每个环境独立挂载；不得包含用户原始路径 |
| Cookie 安全模式 | 本机 HTTP 可显式关闭 `Secure`；客户 HTTPS 默认开启 |
| 演示种子开关 | 仅 `local-demo/demo` 可为真 |
| 日志级别 | 默认 `INFO`；生产不得记录密码、Session、CSRF、密钥或文件正文 |

## 前端配置

- `NEXT_PUBLIC_APP_MODE=demo`：允许当前已冻结的前端演示适配器。
- `NEXT_PUBLIC_APP_MODE=production`：只允许真实 API 适配器；认证失败显示登录页，数据为空显示空状态，服务未配置显示明确状态，任何情况下都不得导入或回退到演示数据作为业务答案。
- API 默认同源 `/api/v1`，避免把内部服务地址和密钥暴露给浏览器。

## 启动护栏

生产模式出现下列任一情况时必须拒绝就绪：

1. 演示种子开关开启。
2. 使用已知演示账号或演示口令。
3. Session、CSRF 或文件加密密钥缺失、过短或相同。
4. 数据库迁移未达到应用要求版本。
5. 文件存储不可写或加密自检失败。

## 初始化契约

- `local-demo` 可以通过显式命令创建脱敏演示数据，命令必须可重跑且只作用于 Demo 数据库。
- `customer-template` 只允许通过一次性初始化命令创建首个企业与企业管理员；密码由实施人员现场输入或安全随机生成并立即交付，模板中不保存默认密码。
- 首个管理员首次登录同样强制改密。

## 备份契约

每份备份必须带有环境、企业、数据库迁移版本、创建时间和校验摘要。恢复默认只允许回到相同环境；跨环境恢复必须使用单独的显式受控流程并产生审计记录。
