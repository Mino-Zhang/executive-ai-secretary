## 已交付

### 可运营 Harness

- 管理端一级功能保持为模型服务、编排策略、MCP 工具三项。
- 六段业务 Prompt、术语表和快速规则均可配置；配置保存生成不可变版本、哈希与审计记录。
- 新消息任务快照当前 Harness 版本；重试继续使用原版本。
- 提供模拟、脱敏技术追踪、指标与历史版本恢复。
- 权限范围、注册工具白名单、固定输出 Schema、最多四次工具调用、最大并发三、一次修正规划、数据证据门槛、禁用文件/联网/任意代码由服务端安全内核强制执行。
- 正式链路为：范围快照、快速规则或 Hermes 路由、独立 QuerySpec 改写、Hermes 规划、受控 MCP 并行执行、证据校验、最多一次修正规划、结构化回答。

### 多事业部范围

- 支持 `all_authorized` 与 `selected[]`，并兼容一个发布周期的旧单事业部字段。
- 全部、单选、双选、多选、选满归并全部均已实现。
- 点击“全部”后的任一单项会直接切换为该单项；弹窗不会在连续选择时自动关闭。
- 搜索不清除已选项；应用前可用外部点击或 `Esc` 放弃草稿。
- 发送消息时在同一事务中保存会话范围、消息级范围快照和任务 Harness 版本。
- 会话中变更范围会插入系统分隔；历史回答和重试保留原范围。
- 服务端动态解析全部授权范围，明确选择不会自动扩大，越权范围返回拒绝。

### 工作台与个人隐私

- 日期仅显示在顶部栏；移动端进入标题第二行并按用户时区与语言刷新。
- 删除“今天需要我先看什么？”和“从一个问题开始”的简繁中英文文案，保留三条建议问题。
- 个人称呼、语言、金额单位、回答风格与记忆开关迁移到服务端个人配置。
- 个人配置与长期记忆正文加密存储；管理员接口不返回个人正文、会话正文或完整上下文。
- 单条回答可由董事长二次确认后共享 24 小时诊断，可提前撤销；授权和撤销进入审计。
- 文件上传与文件问答继续关闭；当前未联网，泛化回答被要求明确实时信息限制。
