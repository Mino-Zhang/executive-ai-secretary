# ADR 0003：授权、隐私与审计矩阵

- 状态：第一阶段强制契约
- 日期：2026-07-27

## 授权判定顺序

每个受保护请求依次完成：

1. 验证 Session 是否存在、有效、未撤销且未过期。
2. 验证账号、企业和组织是否启用。
3. 首次登录待改密时，仅开放身份信息、改密和退出接口。
4. 校验 CSRF（所有基于 Cookie 的非安全方法）。
5. 校验角色是否允许该动作。
6. 校验资源所有权或明确的审计授权。
7. 校验事业部数据范围；查询条件必须与授权范围取交集，不能只隐藏前端选项。
8. 对敏感或变更动作写入不可变审计事件。

任一步失败均不返回资源是否真实存在；跨企业资源统一按不可见处理。

## 角色矩阵

| 资源/动作 | `executive` | `enterprise_admin` | `fde` |
| --- | --- | --- | --- |
| 查看/修改本人资料 | 是 | 是 | 是 |
| 查看授权事业部 | 是 | 是 | 按客户授权 |
| 本人会话与消息 | 读写 | 默认不可见 | 默认不可见 |
| 本人项目 | 读写 | 默认不可见 | 默认不可见 |
| 本人文件正文/下载 | 读写 | 默认不可见 | 默认不可见 |
| 本人长期记忆正文 | 读写 | 默认不可见 | 默认不可见 |
| 本人简报 | 读取 | 默认不可见 | 默认不可见 |
| 用户启停、重置密码、撤销 Session | 否 | 是 | 受控实施 |
| 事业部与数据范围配置 | 否 | 是 | 按客户授权 |
| 任务运行状态 | 简化状态 | 读取/重跑允许项 | 运维权限 |
| 系统运行与连接状态 | 简化状态 | 读取 | 读取/处理 |
| 审计事件 | 本人安全事件摘要 | 管理类审计；无正文 | 运维类审计；无正文 |

若未来开放管理员审计高层正文，必须新增独立权限、理由、有效期与高层可见告知，不能通过扩大现有管理员角色隐式实现。

## 事业部范围规则

- 事业部是服务端管理数据，只有完成数据接入且启用分析的事业部才能进入可选列表。
- “全部事业部”是当前用户所有授权且可分析事业部的动态集合，不是绕过范围限制的特殊 ID。
- 请求指定未授权事业部时返回范围错误，不静默扩大或替换为全部范围。
- 后台任务、简报和导出使用创建时固化的授权范围，并在执行前再次校验账号与数据源状态。
- 权限变化后撤销相关缓存，并在后续请求即时生效。

## 审计最小字段

审计事件至少包含：

- 唯一事件 ID、UTC 时间、企业 ID、环境；
- 操作者用户 ID、角色、Session ID 摘要；
- 动作、资源类型、资源 ID、结果；
- 请求 ID、来源 IP 摘要、User-Agent 摘要；
- 事业部范围摘要与变更前后字段名；
- 失败原因代码；
- 事件链或完整性校验字段。

审计中不得记录密码、Session Token、CSRF Token、密钥、完整文件正文、完整消息正文或模型密钥。消息与文件操作只记录资源 ID、大小、类型、状态和必要摘要。

## 审计删除检测

新审计事件按企业分链，并记录连续序号与前一条完整性哈希。每条事件仍使用独立 HMAC；另有一个受 HMAC 保护的链头保存最后序号和尾哈希。校验同时检查单条 HMAC、序号连续性、前序哈希和链头锚点，因此中间删除、尾部删除与链头篡改都可检出。

迁移前的 `audit-v1` 事件保留原验签规则。API 启动时对旧事件的 ID 与哈希生成顺序根摘要，并纳入企业链头锚点。这能检测锚定后对旧记录的删除；已经在升级前发生的删除无法被新系统逆向证明，因此升级必须在受控维护窗口完成，并保留升级前备份和清单签名。

## 幂等写入与并发

带 `Idempotency-Key` 的写请求在业务变更前预占唯一范围（用户、方法、路径和键）。PostgreSQL 使用唯一索引冲突协调：竞争请求会等待首请求事务结束，然后回放与业务变更同一事务提交的状态码和响应。首请求回滚时，预占也一并回滚；同键不同载荷返回冲突；过期记录可被原子重新预占。SQLite 仅用于快速功能测试，生产并发保证以 PostgreSQL 集成测试为准。

## 必测越权场景

1. 未登录访问任何业务 API。
2. 待首次改密账号访问会话或文件。
3. 高层 A 读取高层 B 的会话、项目、记忆或文件。
4. 管理员读取高层会话正文或下载文件。
5. FDE 未经授权读取业务正文。
6. 用户把未授权事业部 ID 写入请求体或查询参数。
7. 仅修改 URL 中的企业 ID、资源 ID 或文件 ID。
8. 缺失、过期或跨 Session 的 CSRF Token 发起写操作。
9. 被撤销 Session 继续调用 API。
10. 生产模式启动演示种子或使用演示口令。
