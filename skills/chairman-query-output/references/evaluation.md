# 评测与验收

## 核心断言

每条回答必须满足：

1. 首句直接回答问题并说明是否需要介入。
2. 关键数字不超过三个，且能在授权工具结果中逐项追溯。
3. 明确时间、范围、比较基准和决策就绪度。
4. 至多一个主图或主表，且证据形态与问题匹配。
5. 动作包含责任人、截止时间和复核指标；缺失值写“待指定/待确定”。
6. 不把预估额、漏斗额或概率金额描述为已兑现收入。
7. 数据不足时拒绝伪精确预测，并指出最小补数要求。
8. 不出现“整体向好”“建议关注”“持续推进”等空判断。

## 回归题集

| ID | 问题 | 预期模板 | 关键断言 |
| --- | --- | --- | --- |
| 01 | 现在整体经营情况怎么样？ | `executive_pulse` | 有比较基准才判断好坏；首句说明是否介入 |
| 02 | 本季度能完成销售目标吗？ | `target_gap` | 必须有目标、周期和兑现口径；否则 `not_ready` |
| 03 | 哪些项目最可能延期？ | `risk_action` | 按影响与紧迫度排序，包含责任人和里程碑 |
| 04 | 最大的五个商机是什么？ | `top_opportunities` | 明确按预估额排序，不把预估额当收入 |
| 05 | 哪两个客户值得我亲自跟？ | `top_opportunities` | 说明介入理由、卡点和下一动作 |
| 06 | 哪个事业部表现最好？ | `decision_memo` | 统一时间窗和口径，避免只按绝对额下结论 |
| 07 | 回款风险多大？ | `risk_action` | 显示逾期暴露、账龄、集中度和责任人 |
| 08 | 商机池足够覆盖缺口吗？ | `target_gap` | 显示覆盖倍数与质量折扣；缺概率口径时不加权 |
| 09 | 今天和昨天相比发生了什么？ | `executive_pulse` | 只突出最重要变化和一个主证据 |
| 10 | 王鹏程和王浩辰谁更值得加资源？ | `decision_memo` | 缺目标/客户池规模时不得评价效率 |

## 五秒测试

让未参与分析的人只看第一屏五秒，然后回答：

- 结论是什么？
- 董事长要不要介入？
- 最大风险或机会是什么？
- 谁在何时前做什么？

四问中少于三问能答出，第一屏失败。

## 机器校验建议

- JSON Schema 校验通过。
- `metrics.length <= 3`。
- `primary_evidence` 最多一个。
- `decision_readiness != ready` 时 `data_quality.issues` 非空。
- 每个事实数字都能匹配 `evidence_refs`。
- `actions` 中空责任人或空截止时间被标准化为 `待指定`、`待确定`，而不是猜测。
